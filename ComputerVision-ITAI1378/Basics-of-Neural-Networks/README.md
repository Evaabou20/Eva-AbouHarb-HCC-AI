# Basics of Neural Networks

## Project Overview

This project provides a hands-on introduction to deep learning by building, training, and evaluating a fully connected neural network using PyTorch. The model learns to classify images as either **chihuahuas** or **muffins**, demonstrating the complete image classification workflow from data preprocessing to model evaluation.

This project was completed as part of **ITAI 1378 – Computer Vision** at **Houston City College**.

---

## Objectives

- Understand the fundamentals of neural networks.
- Build a fully connected neural network using PyTorch.
- Prepare image datasets for deep learning.
- Train and validate an image classification model.
- Evaluate model performance using validation data.
- Visualize prediction probabilities.

## Key Learning Outcomes

This project introduced the complete deep learning workflow, including preparing image datasets, designing a neural network, training the model through multiple epochs, evaluating validation performance, and interpreting prediction results. It also strengthened my understanding of tensors, optimization, loss functions, and the importance of validation when developing machine learning models.

The knowledge gained in this project provided a strong foundation for later work involving convolutional neural networks (CNNs), object detection, and other advanced computer vision techniques.
