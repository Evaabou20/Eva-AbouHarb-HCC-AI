# Image Processing Fundamentals

## Project Overview

This project explores the foundational concepts of digital image processing using Python, OpenCV, and Pillow. Through a series of hands-on exercises, I learned how computers represent images as matrices of numerical values and how image processing techniques enhance visual information before it is analyzed by computer vision and AI models.

This project was completed as part of **ITAI 1378 – Computer Vision** at **Houston City College**.

---

## Objectives

- Understand how digital images are represented in computers.
- Explore RGB color channels and grayscale conversion.
- Apply point operations to modify image brightness and contrast.
- Perform neighborhood filtering using convolution kernels.
- Improve image quality using Histogram Equalization and CLAHE.
- Understand the role of image preprocessing in computer vision.
