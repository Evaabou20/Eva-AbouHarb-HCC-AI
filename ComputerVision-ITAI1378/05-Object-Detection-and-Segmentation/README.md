# Object Detection and Segmentation

## Project Overview

This project explores two fundamental computer vision tasks beyond image classification: object detection and image segmentation. Using state-of-the-art pretrained models, I implemented object detection with YOLO11, instance segmentation with YOLO11-seg, and foundation model segmentation using Meta's Segment Anything Model 2 (SAM 2).

The project demonstrates how modern computer vision systems identify objects, locate them with bounding boxes, generate pixel-level masks, and compare specialist models with foundation models.

This project was completed as part of **ITAI 1378 – Computer Vision** at **Houston City College**.

---

## Objectives

- Understand the differences between classification, object detection, and segmentation.
- Perform object detection using YOLO11.
- Generate instance segmentation masks using YOLO11-seg.
- Explore prompt-based segmentation using SAM 2.
- Compare specialist detection models with foundation models.
- Learn common evaluation metrics used in computer vision.

## Key Learning Outcomes

Through this project, I learned how modern computer vision systems move beyond image classification by identifying multiple objects, locating them with bounding boxes, and producing pixel-level segmentation masks. I gained practical experience using YOLO11 for object detection, YOLO11-seg for instance segmentation, and SAM 2 for prompt-based segmentation.

I also strengthened my understanding of evaluation metrics such as IoU, precision, recall, and mAP, as well as the trade-offs between specialist models and foundation models. These concepts prepared me for developing a real-world computer vision application in the course's final project.
