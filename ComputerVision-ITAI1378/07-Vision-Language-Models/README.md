# Vision-Language Models

## Project Overview

This folder contains two projects completed as part of **ITAI 1378 – Computer Vision** at **Houston City College**. Together, these projects explore Vision-Language Models (VLMs), which combine computer vision and natural language processing to understand both images and text.

The projects introduce modern multimodal AI through hands-on experiments with **CLIP** and **BLIP**, demonstrating how these models perform tasks such as zero-shot image classification, image retrieval, image captioning, and visual question answering.

---

## Objectives

- Understand how Vision-Language Models connect images and text through shared embedding spaces.
- Explore zero-shot image classification using CLIP.
- Perform image-text retrieval using similarity embeddings.
- Generate image captions with BLIP.
- Answer questions about images using Visual Question Answering (VQA).
- Compare discriminative and generative VLM architectures.
- Learn the fundamentals of fine-tuning multimodal models.

## Key Learning Outcomes

Through these projects, I gained practical experience working with modern Vision-Language Models and understanding how they bridge computer vision and natural language processing. I explored how CLIP aligns images and text in a shared embedding space for zero-shot classification and retrieval, while BLIP extends these capabilities by generating captions and answering questions about images.

These projects strengthened my understanding of multimodal AI, prompt design, embedding similarity, and the strengths and limitations of current Vision-Language Models.
