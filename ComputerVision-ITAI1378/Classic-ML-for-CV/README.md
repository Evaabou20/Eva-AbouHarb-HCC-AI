# Classic ML for Computer Vision

## Project Overview

This project explores traditional machine learning techniques for computer vision using feature engineering and classical classification algorithms. Instead of using deep learning, the project focuses on extracting meaningful image features and training machine learning models to recognize faces.

This project was completed as part of **ITAI 1378 – Computer Vision** at **Houston City College**.

---

## Objectives

- Understand how classical computer vision differs from deep learning.
- Extract meaningful image features using traditional techniques.
- Train machine learning classifiers for image recognition.
- Compare feature extraction methods and evaluate model performance.
- Analyze model generalization using validation and cross-validation.

- 400 grayscale face images
- 40 individuals

## Key Learning Outcomes

Through this project, I learned how traditional computer vision systems rely on handcrafted image features before applying machine learning algorithms. I gained experience using HOG and LBP for feature extraction, training SVM and Random Forest models, evaluating performance, and understanding how proper validation helps build models that generalize well to unseen data.

This project strengthened my understanding of the foundations of computer vision and provided valuable context for later projects involving convolutional neural networks and deep learning.
