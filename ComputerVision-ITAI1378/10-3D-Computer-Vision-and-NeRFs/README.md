# 3D Computer Vision and Neural Radiance Fields (NeRFs)

## Overview

This repository contains our group presentation for **ITAI 1378 – Computer Vision** at **Houston City College**. The presentation introduces the fundamentals of **3D Computer Vision** and explains how **Neural Radiance Fields (NeRFs)** enable realistic 3D scene reconstruction using deep learning.

---

## Topics Covered

- Introduction to Computer Vision
- What is 3D Computer Vision?
- 2D Vision vs. 3D Vision
- Traditional 3D Reconstruction
- Structure from Motion (SfM)
- Multi-View Stereo (MVS)
- Neural Radiance Fields (NeRFs)
- Advantages and Limitations of NeRFs
- Real-World Applications
- Future Directions
