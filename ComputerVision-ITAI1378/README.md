# Computer Vision (ITAI 1378)

Welcome to my Computer Vision portfolio for **ITAI 1378 – Computer Vision** at **Houston City College**.

This repository showcases projects completed throughout the course, covering traditional computer vision techniques, deep learning, object detection, generative AI, vision-language models, reinforcement learning concepts, and a semester-long computer vision project.
