# Computer Vision Fundamentals

## 📖 Overview

This folder contains the introductory assignments completed at the beginning of the Computer Vision course. These assignments provided the foundational knowledge and tools required for the remainder of the course, including version control, Jupyter Notebooks, Google Colab, and an exploration of real-world computer vision applications.

---

## 🎯 Learning Objectives

- Learn the fundamentals of GitHub and version control.
- Become familiar with Google Colab and Jupyter Notebooks.
- Understand how computer vision is applied in real-world scenarios.
- Develop technical writing and research skills.
